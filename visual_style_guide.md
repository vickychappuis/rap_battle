## The vibe

**Late-’70s / early-’80s Bronx party-flyer energy**—like a handbill you’d get pressed into your palm: **photocopied**, slightly misregistered, high-contrast, and *confidently handmade*. The graphic language is a mash of **Art-Deco “neo-deco” frames** + **rub-on / dry-transfer type** + **collaged photos** + **starbursts/arrows**—but kept disciplined so it feels *sharp*, not costume-y. ([Sothebys.com][1])

Texture-wise: **Xerox grain, fold marks, tape shadows, halftone dots**, and “cheap paper” warmth. The overall impression should feel **loud in hierarchy, quiet in polish**—a real artifact, not a slick app skin.

Design posture (what it *feels* like):

* **Brutalist editorial structure** (big type, hard edges, obvious grid)
* **Restrained maximalism** (collage + stamps + marginalia used like seasoning)
* **Analog authenticity** over “graffiti font everywhere” ([Eye on Design][2])

If you want an even tighter label: **“Funky Nous Deco” / early hip-hop flyer visual language** (PHASE 2 lineage) paired with **Buddy Esquire-style neo-deco handbills**. ([Eye on Design][2])

## Color palette

Early flyers read like **black ink on colored stock**—so think *paper first*, accent second.

**Base (always on)**

* Ink Black: **#111111**
* Paper Cream: **#F2E8D5**
* Xerox Gray: **#B9B2A6**
* Dusty Margin: **#E6DDCC**

**Paper-stock options (pick one “paper” per page)**

* Canary flyer yellow: **#F4E34A**
* Bubblegum pink: **#FF7AA2**
* Mint/green stock: **#9BE7B1**
* Sky blue stock: **#8FD3FF**

**One spot accent (use sparingly)**

* Marker Red: **#E11D48**
* Safety Orange: **#FF4D00**
* Electric Cyan: **#00D4FF**

Rule of thumb: **mostly monochrome + colored-paper feel + one loud accent** (so it still feels like a photocopy/handbill, not a neon UI theme). ([Sothebys.com][1])

## Type (authentic without going “graffiti display font”)

A solid “flyer” stack:

**Headlines (condensed, poster punch)**

* **Bebas Neue** *or* **Anton**
  (Alt paid/reference vibe: *Trade Gothic Condensed / Franklin Gothic Condensed*.)

**Body (clean, modern, disappears)**

* **Inter** *or* **Libre Franklin**

**Numbers / timing / metadata (equipment / tape-deck energy)**

* **IBM Plex Mono**

**Handstyle**
Don’t rely on a graffiti font for navigation/body. Instead: use **a few custom SVG stamps** (LIVE / ROUND / NO BITIN’) so the hand-made energy reads as *real print ephemera*, not a theme pack. (This matches how flyers mixed clean type with hand touches.) ([Rare and Manuscript Collections][3])
